# JuegoDeLaVida
Desarrollado por:
- Adalberto Ruiz Chavez

Este proyecto implementa el Juego de la Vida de Conway, un autómata celular creado por el matemático John Conway.
El programa se ejecuta directamente en la consola y utiliza una matriz de 80 × 80 celdas. El usuario puede seleccionar las células que estarán inicialmente vivas y posteriormente iniciar la simulación.

La evolución de las células se realiza siguiendo las reglas del Juego de la Vida:

- Una célula viva sobrevive si tiene 2 o 3 vecinos vivos.
- Una célula viva muere si tiene menos de 2 o más de 3 vecinos vivos.
- Una célula muerta nace cuando tiene exactamente 3 vecinos vivos.

Controles

↑	Mover cursor hacia arriba
↓	Mover cursor hacia abajo
←	Mover cursor hacia la izquierda
→	Mover cursor hacia la derecha
ENTER	Activar/desactivar una célula
S	Iniciar la simulación
Q	Salir
